# ระบบขอสอบแก้ตัวสำหรับนักเรียน

ระบบ Web App สำหรับให้นักเรียนตรวจสอบวิชาที่ยังไม่ได้สอบแก้ตัว และขอเลือกวันสอบแก้ตัวได้ด้วยตนเอง

## คุณสมบัติ

- นักเรียนกรอกเลขประจำตัว → ดูรายวิชาที่ยังไม่มีผลสอบแก้ตัว
- แสดงชื่อวิชา, รหัสวิชา, ครูประจำวิชา
- เลือกวันสอบแก้ตัวจากวันที่ครูเปิดรับ (ดึงจากชีต Teachers)
- ส่งแจ้งเตือนไปยังกลุ่ม Telegram อัตโนมัติ
- บันทึกประวัติการขอสอบแก้ตัวลง Google Sheets (คอลัมน์ T, U, V)

## โครงสร้างไฟล์

```
├── Code.gs          # โค้ดฝั่งเซิร์ฟเวอร์ (Google Apps Script)
├── index.html       # หน้าเว็บสำหรับนักเรียน
└── README.md
```

## การติดตั้ง

### 1. สร้างโปรเจกต์ใหม่ใน Google Apps Script
- ไปที่ [script.google.com](https://script.google.com)
- สร้างโปรเจกต์ใหม่
- วางโค้ดจาก `Code.gs` และสร้างไฟล์ HTML ชื่อ `index` แล้ววางโค้ดจาก `index.html`

### 2. ตั้งค่า Script Properties
ไปที่ **Project Settings → Script properties** แล้วเพิ่มค่าดังนี้:

| Property          | คำอธิบาย                          |
|-------------------|-----------------------------------|
| `SPREADSHEET_ID`  | ID ของ Google Spreadsheet         |
| `TELEGRAM_TOKEN`  | Token ของบอท Telegram             |
| `TELEGRAM_CHAT_ID`| Chat ID ของกลุ่มที่ต้องการส่งแจ้งเตือน |

### 3. Deploy เป็น Web App
1. คลิก **Deploy → New deployment**
2. เลือก Type: **Web app**
3. Execute as: **Me**
4. Who has access: **Anyone**
5. คลิก Deploy แล้วคัดลอกลิงก์มาใช้งาน

## โครงสร้างข้อมูลใน Google Sheets

### ชีต `RetakeResults`
ใช้คอลัมน์หลัก:
- C: เลขประจำตัวนักเรียน
- D: ชื่อนักเรียน
- G: รหัสวิชา
- H: ชื่อวิชา
- N: ผลการสอบแก้ตัว (ว่าง = ยังไม่ได้สอบ)
- P: ชื่อครูแบบสั้น (เช่น ครูธนกาญจน์)
- **T**: วันเวลาที่นักเรียนขอสอบแก้ตัว
- **U**: วันที่นักเรียนเลือก
- **V**: สถานะ ("นักเรียนขอสอบแก้ตัวแล้ว")

### ชีต `Teachers`
- B: ชื่อครูเต็ม
- C: วันที่ครูรับสอบแก้ตัวได้ 1
- D: วันที่ครูรับสอบแก้ตัวได้ 2
